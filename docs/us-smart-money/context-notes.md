## 채택하지 않은 안과 이유
- **앱 유니버스(미국 ~600종)만 스캔** — 보고서가 보라는 스몰캡 클러스터가 모집단 밖. CLAUDE.md "상위 N 은 모집단의 구멍을 물려받는다"(SPCX 사고) 그대로라 기각.
- **PC 러너(작업 스케줄러)** — SEC 는 로그인이 없어 PC 에 둘 이유가 없고, PC 꺼지면 공백. Vercel 크론 커서 분할로 대체(어느 클로드에서 작업하든 무관).
- **클라우드 예약 에이전트로 수집** — 답이 하나인 수집에 LLM 을 매일 태울 이유 없음(2026-09-17 스킬 정비 원칙).
- **새 Supabase 테이블** — DDL 을 이 세션에서 못 돌리고, 30일 × 일별 문서면 app_cache 로 충분. 나중에 표본이 커지면 이전.
- **4개 보고서를 메뉴 4개·탭 4개로** — 학생에겐 질문 하나("큰돈이 어디로")라 한 화면 세로 쌓기. 모바일 시안(09-18)에서 탭보다 스크롤이 쉬운 것 확인.
- **종합 점수·이달의 추천** — 보고서마다 잣대가 달라 합치면 가짜 정밀. WHAT 은 6축의 일.
- **LLM 요약 문단("바닥 심리")** — 근거 없는 서술 위험. 수치 문장으로 대체.

## 절 1 유동성 — 채택하지 않은 안 (2026-09-19)
- **3개월 Bull/Base/Bear 확률 시나리오** — 근거 없는 확률은 가짜 정밀. 국면·유리/불리 섹터는 4계절 SSOT(`SEASON_META.favored/unfavored`)가 이미 답한다 → 그걸 그대로 표시.
- **FOMC 의사록 톤 분석(LLM)** — FOMC 디코더가 별도 화면에 있고 인용 검증(srcIdx) 한계가 CLAUDE.md 에 기록돼 있다. 여기선 FF 선물 방향(macro-regime)만.
- **G5 중앙은행 공조** — 무료 일관 소스 없음 → 표시 안 함.
- **달러 인덱스(DXY)·BTC 를 새 심볼로** — 상관 레이더가 UUP·BTC-USD·SPY 를 쓴다. 같은 축을 다른 심볼로 재지 않는다(제2원칙).
- 신규 수집은 FRED DRTSCILM(은행 대출태도, 분기) 하나뿐. 나머지 넷은 기존 라우트 응답 조립.
