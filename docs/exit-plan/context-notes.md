# 출구 플랜 — 컨텍스트 노트 (결정 기록)

## 채택하지 않은 안과 이유
- **"매수 후 최고가" 샹들리에** → 기각. 학생마다 매수일이 달라 같은 종목 값이 갈림(제2원칙 위반) + 워처는 종목 단위 스캔이라 개인화 불가. 표준 22봉 창은 트레일링 성질을 유지하면서 전원 동일 값.
- **R배수(2R/3R) 익절 기준** → 기각. 진입 시점 ATR을 모르니 현재 ATR로 근사하면 가짜 정밀. 수익률 + 에너지 소진 신호 결합으로 대체.
- **atrStop(현재가−2ATR)을 보유 손절선으로** → 기각. 현재가에서 파생되므로 정의상 항상 현재가 아래 = 이탈 판정 불가. 구조 방어선은 구름 하단(고정적 레벨)으로.
- **재고적체·좀비 신호 포함** → v1 보류. buildSignalMetrics 호출이 무겁고, Jarvis 펀더 판정(user_daily_briefings)이 이미 그 룰들을 반영한 결과라 이중계상.

## 채택하지 않은 안과 이유 (thesis 점검)
- **FOMC 축 대조** → 제외. 시장 전체 기조라 종목 thesis가 아님(적중률 채점엔 유효하나 '산 이유' 점검엔 노이즈).
- **가장 최근 스냅샷 사용** → 기각. '원래 산 이유'가 thesis — 가장 이른 유효 기록 채택(DCA 재확인은 별개).
- **thesis broken을 매도 신호로 점수화** → 기각. 표시·action 한 줄 병기만(WHAT/WHEN 분리·자동 판정 강요 금지).
