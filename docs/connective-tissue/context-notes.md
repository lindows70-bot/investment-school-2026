# 연결 조직 — 컨텍스트 노트 (결정 기록)

## 채택하지 않은 안과 이유 ← 가장 중요

### ❌ 추천 지도(reco-hub)에 '오늘의 대표 종목' 표시 — **기각**
후보 목록에 올려뒀다가 착수 직전에 기각했다.

**왜 기각했나**
1. **지도의 목적이 흐려진다.** reco-hub 는 "6개 렌즈가 왜 서로 다른 1위를 주는가"를 설명하는
   **안내 지도**다(파일 헤더에 '정적 안내 지도 · 데이터 fetch 0'으로 설계가 명시돼 있다).
   여기에 오늘의 종목을 얹으면 **일곱 번째 추천 화면**이 되어, 정작 학생이 "어디로 가야 하지"를
   해결하러 온 화면이 또 하나의 선택지를 던지는 곳이 된다.
2. **비용이 크다.** 렌즈 6개의 오늘 1위를 채우려면 서로 다른 API 6개를 호출해야 한다.
   대시보드 탭 지연 마운트로 동시 fetch 를 줄여온 방향과 정반대다(실측 이력: 숨은 탭 42개가
   동시에 fetch 해 다른 기능이 타임아웃 났다).
3. **이미 해결됐다.** 각 렌즈 카드는 실제 화면으로 링크되고, 그 화면의 종목마다
   `StockActionChips`(🎯판정·📉차트·⭐관심·➕보유등록)가 붙었다. 학생은 지도 → 렌즈 화면 →
   종목 액션으로 **두 클릭 안에** 도달한다. 지도에 종목을 복제할 이유가 사라졌다.

**대신 한 것**: '읽는 법'의 "매수 전엔 종목 리서치로 확인하라"가 **글로만** 있고 링크가 없었다 —
거기에 실제 링크를 걸었다. 안내는 갈 수 있어야 안내다.

**다시 검토할 조건**: 학생이 "지도만 보고 나가버린다"는 실사용 신호가 나오면 재고. 그때도
6개 렌즈 전부가 아니라 통합추천 1종만 가볍게 붙이는 선에서.

## 검증에서 발견한 것

### 🏦 SEP 점도표에 출처가 없었다 (데드코드 정리 중 발견)
데드코드를 지우다 `LATEST_SEP` 이 실제 사용 중임을 확인했고(조사 에이전트는 '참조 0'으로
오판 — 재검증이 잡았다), 그 과정에서 **더 큰 문제**를 봤다: 학생 화면에
`SEP 점도표 3.88%→2.13% 우하향과 일치` 가 나가는데 **언제 전망인지 표기가 없었다.**
실제 값은 2025년 3월 FOMC 기준으로 당시 기준 17개월 전이었다.

FOMC SEP 는 무료 라이브 API 가 없어 수동 갱신이 정당한 '정적 참조 데이터'다. 하지만 그
예외의 조건은 **'출처를 남길 것'**인데 그걸 안 지키고 있었다. `publishLabel` 필드가 원래
있었는데 어디서도 쓰이지 않았다.
→ 세 분기 문구 전부에 발표 회차를 병기하고, 6개월 넘게 갱신이 없으면 `⚠️ N개월 전 전망`을
   자동 계산해 붙였다(갱신을 잊어도 학생이 스스로 안다).

### 🧹 같은 데이터를 구형·신형이 이중 보유
SEP 를 구형(`DOT_RATES`/`SEP_TABLE`, 축 y2025~)과 신형(`LATEST_SEP`, 축 y2026~)이 함께
들고 있었다. 구형은 외부 참조 0. 한쪽만 갱신하면 조용히 갈라지는 구조라 제거했다.

### 🔒 보호 경로 13개 누락
브리핑·성적표·승패 등 13개가 middleware 밖에 있었다. 데이터는 API 가 401 로 막지만,
비로그인 학생은 **빈 화면을 보고 '고장났다'고 오해**한다(브리핑만 "로그인하면 보입니다"를
따로 처리하고 나머지는 그냥 비어 보였다). 라이브 13개 전부 307 리다이렉트 확인.

## 임계값·규약
- `StockActionChips.only` — 축에 맞는 액션만 노출한다. 보유 중인 종목에 '보유 등록'을,
  정리 후보에 '관심 담기'를 띄우면 화면이 학생에게 엉뚱한 행동을 권하는 셈이 된다.
- `?add=` 딥링크는 **티커·종목명만** 채운다. 수량·단가 자동 채움은 자동매매 금지 원칙 위반
  소지가 있고, 무엇보다 학생이 실제 체결 내역을 확인하지 않고 기록하게 만든다.
