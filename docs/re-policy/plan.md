# 🏛️ 부동산 정책 레이더 — 설계 (2026-08-09)

## 목적

앱은 부동산의 **가격·수급·공급·사이클**을 다 보여주는데, 그 모든 것을 한 번에 흔드는
**정부 정책**만 빠져 있다. 학생은 대책을 뉴스로 접하고 앱과 따로 해석한다.

이게 해결되면 학생은 두 질문에 답할 수 있다 —
1. **"지금 무엇이 논의되고, 무엇이 이미 시행됐나?"** (예고 ≠ 확정)
2. **"그 정책은 내가 보는 지표 중 무엇을, 언제쯤 움직이나?"** (경로와 시차)

⛔ 답하지 **않는** 것: 정책이 옳은가(정치), 집값이 몇 % 갈 것인가(예측).

## 데이터 (Phase 0 실측 2026-08-09 — 전부 직접 호출해 확인)

### ✅ 채택 ①  국가법령정보 공동활용 API — **1차 출처(확정된 정책)**
`https://www.law.go.kr/DRF/lawSearch.do` · `target=admrul`(행정규칙) / `law`(법률)

부동산 대책은 법률 개정보다 **고시·훈령**으로 집행된다. 그게 여기 다 있다.

- **`sort=ddes` 작동**(발령일자 내림차순) — 최신 2026-08-06까지 확인
- **`org=1613000`(국토교통부 코드) 작동** — 문자열 `org=국토교통부`는 **안 먹는다**(코드여야 함)
- 실전 시뮬: 9개 키워드 × 부처 필터 → **111건 · 2026년 발령 42건**
- 필드(원문 라벨 확인): `행정규칙명` `행정규칙종류`(고시/훈령/예규) `발령일자` `시행일자`
  `소관부처명` `제개정구분명`(제정/일부개정/타법개정/폐지) `행정규칙상세링크`
- 실측된 최근 항목 예: *수도권 분양가상한제 인근지역 주택매매가격 결정지침*(2026-07-27),
  *공동주택 분양가격 산정 시행지침*(07-15), *주택 재건축 판정을 위한 재건축진단 기준*(07-08)

⚠️ **`OC=test`는 샘플 계정**이다. 실서비스는 law.go.kr에서 **무료 OC 발급**(이메일 ID) 필요.

### ✅ 채택 ②  Google News RSS(무인증) — **예고·논의 단계**
6개 정책 키워드 전부 101건(RSS 상한) 수집 성공, 당일 기사 포함.
`market-catalyst`·`crypto-regulation`이 이미 쓰는 검증된 경로라 신규 의존성 0.

### ❌ 기각 (실측 판정 — 추측 아님)
| 후보 | 결과 |
|---|---|
| `korea.kr` 정책브리핑 RSS | **HTTP 404** (메인은 열리나 RSS 경로 없음) |
| `molit.go.kr` 보도자료 | **fetch failed** (서버에서 접근 불가) |
| 토지이음 | HTML 리다이렉트만 — API 아님 |
| 실거래가 API · 부동산원 통계 API | **이미 앱이 사용 중**(중복) |

## 계산 (결정론) — ⛔ AI는 서술만, 판정은 코드

### ① 두 축을 한 타임라인에 — 이 기능의 핵심
| 축 | 출처 | 성격 | 표기 |
|---|---|---|---|
| 📜 **확정** | 법령정보 API | 이미 발령·시행된 고시/훈령 | 발령일 + 시행일 + **원문 링크** |
| 📰 **예고** | Google News | 논의·검토·발표 예정 | 기사일 + 매체 + "확정 아님" 배지 |

**뉴스는 빠르지만 부정확하고, 법령은 느리지만 확정이다.** 둘을 섞지 않고 나란히 놓는다.
학생이 "발표됐다 = 시행됐다"로 오해하는 걸 구조로 막는다.

### ② 4대 전달 경로 분해 + 앱 지표 연결
| 경로 | 판별 키워드 | 닿는 앱 지표 | 시차 |
|---|---|---|---|
| 🏗️ **공급** | 공급·택지·그린벨트·정비·재건축 | 공급 파이프라인(인허가→착공→준공) | **2~3년** |
| 💰 **세제** | 종부세·양도세·취득세·과세 | 매물 출회 → 거래량·미분양 | 6~12개월 |
| 🏦 **금융** | LTV·DSR·대출·보증·PF | 주담대 금리·거래량 | **1~3개월(가장 빠름)** |
| 📍 **규제지역** | 투기과열·조정대상·토지거래허가·분양가상한 | 해당 지역 벌집 국면·거래량 | 즉시 |

**학생이 가장 크게 오해하는 지점**: "공급 대책 발표 = 곧 집값 하락"이 아니다.
착공→입주 2~3년이라 지금 발표는 **2028~29년 물량**이다. 시차로 못 박는다.

### ③ 정책 강도 신호등
🔴 억제(규제 강화·세율 인상·대출 축소) / 🟢 완화 / 🟡 논의 중
⚠️ **가격 방향이 아니라 규제 강도**다. 🔴을 '악재'로 읽히게 하면 정치적 해석이 된다
(억제책은 실수요자에겐 기회일 수 있다). 라벨을 그렇게 쓴다.

### ④ 필터 (실측이 필수로 만든 것)
- **부처 필터**: 국토교통부·기획재정부·금융위원회·국세청만
  (실측에서 '주택공급' 검색에 산업통상부·국가보훈부·고용노동부가 상위로 섞였다)
- **정치 공방 필터**: 뉴스 제목의 `野|與|여당|야당|공방|정치공세|의원|국정감사` 제외.
  검열이 아니라 **시장 영향과 무관한 잡음 제거** — 제외 건수를 화면에 표기해 투명하게.

## 정직 캐비엇 (UI 명시)
- 📜 확정 항목은 **법령 원문 링크**를 함께 준다(2차 해석 없이 확인 가능).
- 📰 예고 항목은 **언론 보도**이며 확정이 아님을 배지로.
- ⛔ **가격 예측 아님** — 정책이 어느 지표를 언제 움직이는지의 **지도**.
- ⛔ 정책의 정치적 평가는 하지 않는다.
- 표본수(법령 N건·기사 N건·기간)를 항상 병기.

## 구현
- `src/lib/rePolicy.ts` — 경로 분류·강도 판정·부처/정치 필터(순수 함수·결정론)

- 배치: 부동산 시장 대시보드 **최상단**(정책은 모든 지표의 상류)
