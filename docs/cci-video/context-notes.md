## 영상이 주장한 규칙

```
세팅 = SMA(100) + CCI(길이도 100)   ← "이평선과 길이를 맞추는 게 중요"(06:00)
매수 = ① CCI +100 상향 돌파(진입 아님) ② 이후 CCI 고점 형성(눌림) ③ 그 고점 재돌파 시 진입
보유 = CCI 가 +100 아래로 내려와도 홀드. **영선(=이평선)을 지키는 동안**(09:00)
손절·익절 = 종가가 이평선 이탈
자동 필터 = 쉬지 않고 오른 자리는 ②의 고점이 안 생겨 신호가 안 난다("힘을 다 쓴 자리")
```

### Ⓒ 영상 핵심 주장 — "CCI 길이를 이평선과 맞춰라"

**두 주장을 갈라야 한다.**

| 주장 | 판정 |
|---|---|
| "CCI 영선 = 같은 길이 이평선" | ✅ **수학적으로 참** — `CCI = (TP − SMA(TP,n)) / (0.015×평균편차)` |
| "그러니 길이를 맞추면 신호가 좋아진다" | ❌ **반증** — −0.15 vs −0.11 / −4.56 vs −3.97 로 오히려 정합 쪽이 미세하게 나쁘다 |

## 왜 −8σ 까지 갔나 (원인 실측)

```
진입 시점 현재가가 SMA100 위로 벌어진 정도   n=301
   평균 +15.2%  중위 +12.1%   ← 이게 곧 손절선까지의 거리
비교) 이평선 위 아무 날        평균 +12.8%  중위 +9.0%
```

**일봉에서 이 규칙은 손절선이 12% 아래인 자리에서 사라고 한다.** 15분봉이면 이 거리가 1% 안팎이라
규칙이 성립하지만, 일봉 SMA100 에선 손실이 그대로 12%짜리가 된다. 승률 22%·손익비 1:1.67 이면 산수가 안 맞는다.

## 영상 내부의 모순

02:20~03:20 에서 **평균회귀(고무줄)** 를 길게 설명해놓고, 정작 진입은 **고무줄이 가장 늘어난 자리에서
더 늘어날 때** 하라고 한다. 우리 `게이트×눌림목`(오늘 유일하게 2.87σ 로 살아남은 셀)이 잘 되는 이유가
정확히 반대다 — **평균으로 되돌아온 자리**(고점 대비 2~8% 되돌림)에서 산다.
겉모양(추세확립 → 되돌림 → 재돌파)은 같아 보였지만 **진입 지점이 정반대**였다.

## 🔎 이 검증이 우리 앱에서 찾아낸 것 (영상과 무관)

**`cciCross100` 이 한 번도 검증된 적이 없었다.** `SignalReader.tsx:146` 이 학생에게
"CCI +100 상향돌파(N봉 전)"를 **매수 이벤트**로 띄우고 있었는데 성적이 붙어 있지 않았다.

|---|---|---|---|---|

baseline 승률이 52.1% 인데 신호 승률이 50.8% 다 — **신호가 있는 쪽이 오히려 낮다.**

→ 조치(사용자 결정): **지우지 않고 `SCREEN_SETUPS` 에 음수로 등재**한다(FVG·liqSweep 과 같은 처방).
  `evaluateSetups` 에 판정을 추가해 실제로 배지가 뜨게 하고, `SignalReader` 이벤트 문구에도

## 남는 것

📐 **"CCI 영선 = 같은 길이 이평선"은 교육 설명으로만 값이 있다.** 고무줄 비유가 직관적이라
학생에게 CCI 를 설명하기 좋다. 다만 **신호가 아니라 설명**이다 — 진입 근거로 쓰면 위 수치가 답이다.
