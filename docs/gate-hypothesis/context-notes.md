# 게이트 가설 — 컨텍스트 노트

## 왜 이 작업이 시작됐나
사용자 제안: *"여태 쌓인 정성적 데이터로 우리만의 최고 기술타점을 개발하면 어떨까?"*
방향은 맞지만 **"개발"로 접근하면 실패가 보장된다**는 게 첫 판단이었다 — 아래 산수 때문.

## 채택하지 않은 안과 이유  ← 가장 중요
- **❌ 조합 탐색(455가지 중 1등 고르기)** — 20봉 수익률 SD 11.23% · n=200 에서 표준오차 0.79%p.
  엣지 0인 신호를 455가지로 섞어도 1등 기대치가 **+2.38%p**. 우리 최고 셋업(+2.77)과 구분 불가.
  CLAUDE.md 에 이미 *"31기법 중 선택이라는 과최적화 여지"* 경고가 있는데, 조합은 그걸 455배로 만든다.
- **❌ 새 게이트 후보 발굴** — 게이트를 찾는 순간 그것도 탐색이다.
  이미 측정된 **대표본 상태형 2개(greenState n=3,026 · timeFilled n=3,166)** 만 쓴다.
- **❌ 양수 트리거에 게이트 걸기** — "좋은 걸 더 좋게"는 확증편향이다.
  **음수 트리거(pullback −0.95 · bullDiv −0.9)를 양수로 뒤집어야** 게이트의 힘이 증명된다.
- **❌ 기간 분할 hold-out** — 국면까지 분리되는 장점은 있으나 표본이 급감하고 그 기간이
  특정 장세면 결론이 흔들린다. **종목 분할 채택**(사용자 결정) — 우리 표본의 진짜 약점이
  "같은 80종에서만 쟀다"이기 때문.
- **❌ 4개 조합을 모두 1차 검정으로** — best-of-4 기대 최고치 ≈ +0.8%p 라 +1.0 기준이 소음과 가깝다.
  **1차는 `prime` 재현 단 하나**로 좁혔다. 나머지는 탐색적 보고.

## 임계값 근거
- `+1.0%p` — 기존 SCREEN_SETUPS 중위권(timeFilled +1.04 · squeezeFired +1.01) 수준. 이 아래면 채택 의미 없음.
- `n ≥ 200` — 표준오차 0.79%p 확보(측정값 SD 11.23% 기준).
- `부호 동일` — 오늘(2026-08-28) 볼린저+RSI 를 죽인 바로 그 기준. 한 시장에서만 나오면 표본이 사실상 하나.
- `최다 종목 ≤ 30%` — backtest-autopsy 2단 기존 기준 그대로.

## 게이트 정의는 SSOT 를 그대로 쓴다
`entryTiming.timingFromCandles` 의 신호등 green = `aligned(EMA112 > EMA224) && cloud === 'above'`
(구름은 26봉 전 선행스팬 기준). 백테스트용으로 다시 정의하지 않는다 —
정의가 어긋나면 검증 자체가 무의미해진다.
