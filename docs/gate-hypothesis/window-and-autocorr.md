### 읽은 것 — 이쪽이 더 중요하다
1. **표본 숫자가 6~26% 로 줄어든다.** 화면의 "표본 3,166" 같은 숫자는 **겹치는 20봉 창을 센 것**이라
   독립 관측이 아니다. 그대로 읽으면 확신을 크게 부풀린다.
2. **보정 후 대부분이 1σ대** = 표본 우연과 구분되지 않는다.
   상승추세 유지(1.12σ)·기간조정 충족(1.60σ)·눌림목(1.37σ)·다이버전스(0.87σ).
   **앱이 이 값들을 확정처럼 보여주고 있다.**
3. **2σ를 넘는 건 둘뿐** — PRIME(2.68σ)·게이트×눌림목(2.87σ). 게이트가 붙은 셀만 살아남았다.
4. 접은 뒤 edge 가 **오히려 올랐다**(1.22 → 1.40). 겹친 신호가 성과를 희석하고 있었다는 뜻.

## 종합 — 게이트 가설은 살아 있다, 단 한 갈래에서만
`게이트×눌림목`은 **창 4개 전부 양수 + 자기상관 보정 후 2.87σ**로 6개 셀 중 유일하게 두 검사를 통과했다.
다이버전스 갈래는 창마다 부호가 뒤집히고 보정 후 0.87σ — 사실상 신호가 아니다.

**그래도 지금 채택하지 않는다.** 이 결과는 hold-out 검정이 아니라 같은 데이터의 재분석이다.
→ 다음 사전등록의 **1차 검정 대상 확정**: `게이트×눌림목`, 새 종목 hold-out 에서.
