# 🧮 금리 3형제 (명목 = 실질 + BEI) — 설계 (2026-08-13)

## 목적
미국채 10년 금리를 셋으로 쪼개 보여준다 — 명목(DGS10) = TIPS 실질(DFII10) + 기대인플레(BEI·T10YIE).
학생이 "금리가 올랐다"에서 한 발 더 — **무엇이 올린 금리인가**(돈의 진짜 값 vs 물가 기대)를 읽게 한다.
실질 주도 상승은 성장주·장기채에 부담, BEI 주도 상승은 실물자산 상대 유리 — 원인이 달라야 대응이 다르다.

## 데이터 (Phase 0 실측 2026-08-13)
- ✅ FRED `DGS10`·`DFII10`·`T10YIE` — 일별·%·최신 T+1~2. **항등식 오차 0.0000%p**(250일 검사) —
  T10YIE 자체가 DGS10−DFII10 로 만들어진다. 즉 셋의 "상관"은 통계가 아니라 **항등식(분해)**이다.
- 재사용: 없음(신규 계열 2종 — DGS10 은 crisis-radar 에 이미 있으나 시계열이 필요해 lib 이 직접 수집)

## 계산 (결정론 — src/lib/realYield.ts SSOT)
- 60일 변화 분해: Δ명목 = Δ실질 + ΔBEI. 주도 판정: |Δ명목| ≥ 0.15%p 일 때 큰 성분(≥55% 기여)이 주도.
- 수준 판정: 실질 ≥2% 긴축적 / 1~2 중립 / <1 완화적(2010년대 평균 ~0.5%, 2022 이후 2%대 — 서술 근거).
  BEI 1.8~2.5 = 기대 고정(연준 목표 2% 부근) / >2.5 기대 이탈 / <1.8 디스인플레·수요 우려.
- 차트: 2년 일별 → 주 1점 다운샘플(payload 절약), SVG 3선.

## 정직 캐비엇 (UI 명시)
BEI 는 유동성·리스크 프리미엄이 섞여 순수 기대인플레보다 약간 왜곡될 수 있다. 임계값은 역사 서술 기준이지 백테스트 수치가 아니다.
