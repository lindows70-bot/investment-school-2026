# 위기 신호등 — 간편 모드 홈에서 한눈에 (2026-11-21 착수)

## 목적

2026년 11월, 나스닥이 꼭대기에서 −18%·코스피가 −47% 내려오며 "제2의 닷컴버블" 이야기가 돈다.
학생은 앱을 켜도 **"지금 얼마나 위험한가"를 한 화면에서 볼 곳이 없다** — 위기 레이더·수익률곡선·빚투 레이더·막스 시계추가
전부 분석 화면(선생님 대시보드) 탭에 흩어져 있고, 간편 모드에는 공포·탐욕 지수 하나뿐이다.
그래서 뉴스 제목에 반응하게 된다. 포기하는 것: 예측(언제 터지나) · 종합 점수(가짜 정밀) · 매매 지시.

## 종합 — 점수가 아니라 개수

- 표시의 주인공은 **"빨강 n · 노랑 n · 초록 n"** (영상 EP55 와 같은 문법).
- 큰 등 색(한눈용) = 빨강 3개 이상이면 빨강 / 빨강 1개 이상 또는 노랑 3개 이상이면 노랑 / 그 밖 초록. 규칙을 화면에 그대로 적는다.
- 잰 등이 4개 미만이면 종합을 쉰다('못 가져옴'을 초록으로 세지 않는다).

## 캐비엇

- 신호등은 예측이 아니다(금리차 리드타임 0~34개월 · 오경보 있음). 화면 머리에 적는다.
- 주식 값 등은 최근 몇 년 대부분 빨강이다(CAPE·버핏 지표) — 그래서 종합이 초록인 날은 드물다. 사실이라 그대로 둔다.
- 설비투자 비율은 분기 값이라 계절성이 있다 → 1년 전 **같은 분기**와 나란히(날짜로 찾는다 — 인덱스 금지).
