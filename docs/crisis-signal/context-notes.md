## 2. 채택하지 않은 안

- **종합 점수(0~100)** — 기각. 등 7개에 가중치를 줄 근거가 없다(가짜 정밀). 영상도 개수만 말한다("빨강 둘, 노랑 둘…").
- **막스 ①② 를 뉴스 건수·검색량으로 대용** — 기각. 믿음의 대용 지표는 지어낸 것이 된다. "숫자로 못 잼"이라고 적는다.
- **문서의 비교 수치(나스닥 P/E 200배·순이익률 13% 등)를 화면에 싣기** — 기각. 출처를 못 댄다(출처 없는 수치 금지).
- **us-liquidity 대신 macro-weather 를 직접 불러 HY 색을 다시 판정** — 기각. 같은 값을 두 번 판정하면 두 화면이 갈린다. 임계는 상수로 뽑아(HY_WARN_PP 등) 한 곳에서.
- **삼의 법칙에 노랑(0.3%p)** — 기각. 정의에 없는 선을 만들게 된다. 이 등은 두 색.
- **설비투자 최근 4분기 합(TTM)** — 기각. 야후가 분기를 빼먹어(아마존 2026-06) 날짜로 4개를 못 채운다. 최근 분기 + 1년 전 같은 분기(계절성 통제).
- **새 크론으로 미리 데우기** — 보류. Hobby 크론은 모니터와 1:1 등록이 필요하고, 캐시가 식어도 홈의 다른 카드는 따로 뜬다. 느리다는 실측이 나오면 그때.

## 3. 만들면서 고친 기존 결함

- **위기 레이더 선행 PER 문구** — 값 17.1배(판정 '보통')인데 설명은 "5년평균 19.8·10년평균 19.1보다 높아 '주의'"로 박혀 있었다(템플릿 문자열에 비교 결과가 글자로 고정). 값에서 뽑도록 고치고 키 v9 → v10.
- **하이일드 스프레드 기준일** — 값만 있고 날짜가 어디에도 없었다. macro-weather `hyDate` → us-liquidity 게이지 `date`(키 v1 → v2, 정리 규칙 동반).
- 임계 리터럴 상수화 — `HY_WARN_PP·HY_BAD_PP·HY_SPIKE_PP`(usLiquidity) · `SAHM_TRIGGER_PP`(yieldCurve) · `FORCED_SPIKE_PCTL`(crisisSignal ← marks-cycle 의 60). 화면에 적는 규칙 문장이 이 상수에서 나온다.

## 4. 미확인 가정 (사용자 "설계/구현해줘" — 내 추측으로 채운 것)

1. **종합 색 규칙**: 빨강 3개↑ = 빨강 / 빨강 1개↑ 또는 노랑 3개↑ = 노랑. 근거는 "절반 가까이 빨강이면 빨강"이라는 직관뿐이다 — 바꾸기 쉽게 상수 3개로 뒀다.
2. **설비투자 선 100%·50%**: 100%는 자연스러운 선(번 돈을 넘으면 빌려야 한다), 50%는 "절반"이라는 말로 설명되는 선. 화면에 "이 앱이 정한 선"이라고 적었다.
3. **심리 등의 양 끝 빨강**: 극단 공포도 빨강으로 칠했다(투매·강제청산 구간). "공포는 기회"라는 역발상 관점에선 반대로 읽을 수 있다 — 문장으로 풀어 적었다.
4. **홈 자리**: 바로가기 바로 아래(내 자산 위). 첫 화면에서 내 자산·리그 타일이 밀리는지는 화면 실측으로 확인.
5. **주식 값 등은 미국 기준**(CAPE·버핏 지표·S&P 500). 코스피 값은 등에 없다.
