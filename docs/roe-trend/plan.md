# 📈 ROE 추세 축 — 설계 (2026-08-08)

## 목적
학생이 종목을 볼 때 앱은 ROE의 **절대 수준**만 말한다(15% 넘으면 가점). 그래서 ROE가
3.5%→−17%→26.8%→**35.6%** 로 되살아난 SK하이닉스와, 40% 언저리를 조용히 유지하는
코카콜라를 **같은 방식으로** 평가한다. 손주부 인터뷰(2026-08)의 핵심 지적이 이것이다 —
*"ROE가 낮았는데 지금 급등하는 기업을 더 선호한다. 현재 주가에 아직 반영되지 않았을 확률이 높으니까."*

이게 해결되면: 학생은 "지금 좋은 회사"와 "좋아지고 있는 회사"를 구분해서 볼 수 있다.

## 데이터 (Phase 0 실측 2026-08-08 · 10종)
- ✅ ROE 시계열 재료 확보: FTS `annual`의 `financials`(netIncome 계열) + `balance-sheet`
  (`stockholdersEquity` ← 없으면 `totalEquityGrossMinorityInterest`). **10/10 종목 4개 연도 성공.**
- ⚠️ 필드명이 종목마다 다르다 — `netIncome` 없이 `netIncomeContinuousOperations` 만 오는 곳이 있다
  (엔비디아·마이크론·애플·카니발·TSMC·코카콜라). **폴백 체인 필수**(이름 추측 금지 원칙).
- 재사용: buffettSell 이 이미 같은 FTS annual 을 호출한다 → 같은 캐시 창에 얹는다(신규 수집 최소).

### 실측이 설계를 바꾼 것 2건
1. **절대 수준으로 등급을 매기면 안 된다** — 애플 ROE **197%·156%**(자사주 매입으로 자기자본이
   극도로 작아진 결과). 이미 앱에 `roeInflated` 가드가 있는 이유와 같은 현상이다.
   → 판정은 **방향(개선/악화)** 으로만. 절대값은 화면에 병기하되 등급 산정에 안 쓴다.
2. **"평균 대비 개선"만 보면 꺾인 종목이 통과한다** — 엔비디아 19.8→69.2→91.9→**76.3**.
   과거 평균 대비로는 +16%p 개선이지만 **최신이 전년보다 하락**이다. "급등 중"이라 하면 거짓말.
   → 조건에 `최신 ≥ 직전 연도`(꺾이지 않았을 것)를 넣는다.

## 계산 (결정론) — `assessRoeTrend(series)`
`improving`: nY≥3 · 최신 ≥ 직전연도 · 최신 − 이전평균 ≥ **+5%p** · 최신 ≥ **10%**
`deteriorating`: nY≥3 · 최신 ≤ 직전연도 · 이전평균 − 최신 ≥ **+5%p**
그 외 `stable`, 데이터 부족은 `na`.

**임계 −5%p 근거**: 기존 해자 침식(총마진 −5%p)과 같은 잣대를 쓴다. 실측 검증 —
개선: SK하이닉스(+31.2%p)·카니발(+44.7%p)·마이크론(+13.8%p) / 안정: 코카콜라(−0.5%p)·
MSFT(−2.3%p)·TSMC. 엔비디아는 '최신 ≥ 직전연도' 조건에서 정확히 걸러진다.

## 버핏 매도 병용 — ⛔ 새 판정기가 아니라 '교차 확인'
해자 침식 판정은 **총마진 그대로** 유지한다. ROE 시계열은 그 판정이 발동했을 때
**같은 방향인지 확인하는 레이어**로만 쓴다:
- 총마진 침식 + ROE도 악화 → detail 에 "자본효율(ROE)도 함께 꺾였습니다" (신뢰도↑)
- 총마진 침식 + ROE는 유지 → "다만 자본효율(ROE)은 유지 중 — 마진은 눌렸지만 아직…" (완화)
이유: 단독 판정기를 늘리면 발동률만 오르고 검증은 안 된다. 인텔 실측(7.9→1.6→−18.9→−0.2)에서
보듯 ROE 단독 규칙은 '최저 후 반등'을 개선으로 읽어 오히려 오판한다.
