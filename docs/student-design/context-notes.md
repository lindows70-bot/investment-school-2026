- **자산 카드 선 차트 없음** — 포트폴리오 일중·일별 시계열이 없다. monthly-pnl 은 거래 로트 되짚기(무거움)라 홈엔 안 넣는다. 빛만 둔다.
- **리그 ↑↓ 칩은 두 장 이상일 때만**(school-league `prevRank` + `prevSnapDate` ≠ 오늘) — 첫 주(10/13 전)엔 순위만.
- **이번 주 기록 건수** — transactions 를 본인 user_id 로 이번 주 월요일(KST)부터 count. 선생님 계정은 RLS 상 전원 거래가 보이므로 user_id 필터 필수(useMySells 와 같은 이유). 0건은 '0건'이 아니라 "아직 없어요 · 기록하기 ›"로.
- **바로가기 4칸 유지, 위치만 지수 아래로** — 시안엔 없었지만 기능 제거는 '물어보고' 칸. 코인·부동산은 다른 카드가 없어 입구가 필요하다.
- **지수 미니 선: 축 라벨 제거** — 769~1023px 에서 라벨이 겹치던 문제의 근본 처방이기도 하다(값은 글자가 말한다).
