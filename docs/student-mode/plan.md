# 학생 간단 모드 (student-mode)

## 목적

투자학교 학생 8명이 앱을 거의 쓰지 않는다. 2026-09-25 실측: 3명은 종목을 한 번도 등록하지 않았고,
학생 등록은 5월 108건 → 6월 3건 · 7월 2건 · 8월 3건 · 9월 0건이다. 가장 많이 등록한 두 명도 가입 당일 이후 0건이다.
원인은 세 가지로 본다. ① 로그인하면 선생님의 연구 터미널(메뉴 34개·대시보드 탭 50개)이 그대로 뜬다.
② 매수 등록이 6자리 코드를 알아야 하는 7칸 폼이다. ③ 실제 매매는 증권사 앱에서 하고 여기엔 다시 적어야 한다.
학생이 폰·태블릿·PC 어디서든 열자마자 **내 돈이 어떻게 됐는지** 보고, **30초 안에 매매를 적을 수 있게** 한다.
선생님 화면과 기존 35개 화면은 그대로 둔다. 학생에게 보이는 첫 경로만 바꾼다.

## 착수 전 확인 6줄 (2026-09-25 사용자 승인 — "이런 식으로 일단 단순화하자. 디테일한 화면은 보면서 결정하자")

```
결과    : 학생 탭 4개(홈·내 자산·리그·배우기) · 3단계 기록하기(+ 버튼) · 종목 상세 · 폰 홈 화면 설치(PWA) · 접속 기록
사용자  : 학생(role=student). 선생님(teacher)은 지금 화면 그대로, 기록하기만 같이 쓴다
왜 지금 : 학생 등록 활동이 9월 0건 — 앱이 학생에게 죽어 있다
성공    : 접속 기록 도입 후 4주, 주 1회 이상 여는 학생 수와 월 기록 건수를 도입 전 기준선과 비교한다
제약    : 기존 계산(SSOT) 재사용 · 디자인 토큰(TK/FS/RAD/SP) · 한국식 등락색 · 개인 데이터 공유 캐시 금지
범위 밖 : 증권사 캡처 자동 등록 · 기존 35개 화면 리디자인 · 선생님 대시보드 변경
```

## 확정된 설계 (캔버스 7판 · 2026-09-26 사용자 승인)

시안: Claude Design 캔버스 https://claude.ai/artifact/4THDHoK28RNSPeCjAcVvsa (투자학교 디자인 시스템 연결)

| 탭 | 역할 | 들어가는 것 |
|---|---|---|
| **홈** | 오늘 시장과 내 소식 (더리치 홈 구조) | 검색창 · 바로가기 타일(배당 달력·거장·실적 일정·코인 랩·부동산) · 내 총자산 한 줄 · **오늘의 한눈 시황 3줄**(규칙 요약) · 지수 카드 · 공포·탐욕(코인/미국 주식) · 주요 일정 · 내 종목 뉴스 · 거장들의 포트폴리오 · 리그 한 줄 |
| **내 자산** | 내 돈 지도 (더리치 내 자산 구조) | 오른쪽 위 **+ 기록** · 총자산·오늘·원금·불어난 돈 · **히트맵**(크기=평가금액, 색=오늘 등락, 코어/위성 묶음) · 자산 성장 차트 · 내 투자 구성 · 오늘의 투자 체크 · 이달 예상 배당금 · 종목 목록 → 종목 상세 |
| **리그** | 친구와 비교 | 내 순위 · 순위표 · 수익률 계산 ? 도움말 · 친구 포트폴리오(비중만) + '왜 수익률이 달랐을까' |
| **배우기** | 매일 하나씩 알려줌 | **오늘의 명언**(출처 확인된 목록에서 순환) · **오늘 알려드려요**(아래 규칙 4종 순환) · 매매 브리핑 · 수업 자료 · 더 알아보기 5분류(분석 모드) |

사용자 결정 기록:
- 선생님 한마디 → **오늘의 매매 브리핑 규칙 요약**으로 대체 (AI 문장 아님)
- **코어·위성만** 쓴다 — '기본 투자·전략 투자' 같은 우리말 병기 금지
- 학생에게 **할 일을 시키지 않는다** — 미션 대신 답을 알려준다
- '오늘 알려드려요' 규칙 **4종 모두, 날마다 돌려가며**: ① PER·성장률 대 업종 평균 ② 산 뒤 수익 대 같은 기간 지수 ③ 다가오는 실적 발표·배당일 ④ 오늘 크게 움직인 내 종목과 그날 뉴스 제목
- 명언은 Claude 가 고른다 — **원문(주주서한·책·메모·연설록)에서 확인된 것만**
- **앱에 이미 구현된 기능의 데이터는 출처를 다시 따지지 않고 그대로 쓴다**(2026-09-26 사용자 지시)

## 구현 순서

1. 접속 기록(테이블 + 앱 열 때 하루 1행) — 기준선이 먼저다
2. 공용 포트폴리오 요약 lib 추출(자산 화면도 같은 함수로)
3. 종목 이름 검색 API
4. 학생 셸(하단 탭 4개·역할별 로그인 착지) + 내 자산(히트맵) + 종목 상세 + 기록하기
5. 홈(시장·소식 카드들)
6. 리그 · 배우기(명언·오늘 알려드려요)
7. PWA(manifest · 아이콘) · 설치 안내
8. 375/768/1280 실측 → 배포 → 4주 뒤 효과 측정
