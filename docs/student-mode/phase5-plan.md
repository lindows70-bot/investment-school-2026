# 학생 간단 모드 5단계 계획 — 간편 화면 안에서 끝나게 (2026-09-27)

> 사용자 지적: "간편 화면에서 뭔가 보려고 누르면 옛 복잡한 화면으로 들어가는 게 맞아? 그걸 원한 건 아닌데. '간편'과 '분석' 둘로 나눠 만들려던 거야."
> 실측: 간편 화면(5탭) 안에 분석 화면으로 나가는 문이 **30개**(바로가기 4 · 카드 더 보기 3 · 종목 상세 1 · 수업 자료 4 · 더 알아보기 16 · 전환 버튼 2).

```

```

## 원칙 두 줄

1. 간편 화면에서 누른 것은 간편 화면 안에서 끝난다(외부 기사만 새 창).
2. 분석 화면으로 가는 문은 상단 전환 버튼 하나. 카드·목록·바로가기 어디에도 분석 화면 링크를 두지 않는다.

## 가벼운 화면 5개 — 무엇을, 어느 API 로

전부 **이미 받는 응답**이다. 새 원천·새 계산·새 캐시 키 없음. 홈 카드와 같은 규칙 함수를 쓰는 곳은 그 함수를 그대로 부른다(두 화면이 다른 말을 하지 않게).

| 화면 | 내용 | 원천(기존) |
|---|---|---|

## 종목 상세 '더 알아보기' (접이식)

- 닫힌 상태 기본. 열면 5칸: PER(뜻 한 줄) · PEG · 시가총액 · 52주 위치(지금 가격이 52주 최고~최저 사이 어디 — 막대) · 업종 · 배당수익률(있으면). ETF·코인은 있는 칸만.
- 원천 `/api/stock-info`(`fundamentals.pe·peg·marketCap·high52w·low52w·sector·dividendYield`). 값이 'N/A'·null 이면 그 칸을 '없음'이 아니라 **'모름'** 으로.
- 분석 화면 링크는 두지 않는다(원칙 2).

## 명언 풀 확장 — 인생 철학가

- 지금 51개(버핏·멍거·린치·보글·마크스·템플턴 — 전부 원문 확인). 여기에 **인생 철학가**(세네카 『루킬리우스에게 보내는 편지』 · 마르쿠스 아우렐리우스 『명상록』 · 에픽테토스 · 벤저민 프랭클린 등 **공개 원문이 있는 인물**)를 20개 안팎 더한다.
- 원칙은 그대로다 — **원문에서 확인된 문장만**(Gutenberg·archive.org 원문 검색), 번역은 투자학교 번역, 화면엔 인물·출처(책·편지 번호) 병기. 후보 목록을 먼저 사용자에게 보인다.
- 쓰임: 오늘의 명언 순환(주식 명언과 섞임) · 거장 카드의 한 줄(그 거장의 확인된 말이 있으면 그것, 없으면 철학가 명언).
