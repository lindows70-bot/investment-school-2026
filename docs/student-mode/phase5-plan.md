# 학생 간단 모드 5단계 계획 — 간편 화면 안에서 끝나게 (2026-09-27)

> 사용자 지적: "간편 화면에서 뭔가 보려고 누르면 옛 복잡한 화면으로 들어가는 게 맞아? 그걸 원한 건 아닌데. '간편'과 '분석' 둘로 나눠 만들려던 거야."
> 실측: 간편 화면(5탭) 안에 분석 화면으로 나가는 문이 **30개**(바로가기 4 · 카드 더 보기 3 · 종목 상세 1 · 수업 자료 4 · 더 알아보기 16 · 전환 버튼 2).

## 착수 전 확인 6줄

```
결과    : 간편 화면 안에서 누른 것은 전부 간편 화면 안에서 끝난다. 가벼운 화면 5개(/s/calendar·gurus·brief·news·realestate) · 종목 상세 '더 알아보기' · 수업 자료를 간편 껍데기 안에서 · 더 알아보기 16개 삭제
사용자  : 학생(선생님도 간편 화면을 볼 수 있음)
왜 지금 : 간편 화면의 5탭 안은 상용 앱처럼 됐는데, 그 안에서 한 번 더 누르면 메뉴 34개짜리 옛 화면으로 떨어진다 — '두 화면으로 나눈다'는 원래 목적이 반만 됐다
성공    : 간편 화면의 모든 링크·버튼의 목적지가 /s 아래이거나 외부 기사(새 창)다 — 유일한 예외는 상단 '분석 화면' 전환 버튼. 검증 스크립트가 이를 매일 센다(0건이어야 통과)
제약    : 새 원천 없음(이미 받는 API 만) · 개인 데이터는 브라우저·본인 세션만 · 토큰 · 한국식 등락색 · 없음/못 가져옴 구분 · 폰·태블릿·PC 세 폭 검수(늘)
범위 밖 : 옛 분석 화면 리디자인 · 학생의 분석 화면 진입 차단(사용자 결정: 문은 하나지만 누구나 들어갈 수 있다) · 새 계산·새 LLM
```

## 사용자 결정 (2026-09-27)

| 결정 | 내용 |
|---|---|
| 분석 화면으로 가는 문 | **상단 '분석 화면' 전환 버튼 하나뿐**. 막지는 않는다 — 누구나(학생 포함) 들어갈 수 있다. 주소를 직접 쳐도 막지 않는다 |
| 간편 화면 안의 링크 | **전부 간편 화면 안에서 끝난다** |
| 부동산 | 중요한 테마 — 빼지 않고 **배우기 탭에 간편 버전**을 만든다 |
| 순서 | **계획 문서부터**(이 문서) → 검토 → 구현 |

## 원칙 두 줄

1. 간편 화면에서 누른 것은 간편 화면 안에서 끝난다(외부 기사만 새 창).
2. 분석 화면으로 가는 문은 상단 전환 버튼 하나. 카드·목록·바로가기 어디에도 분석 화면 링크를 두지 않는다.

|---|---|---|

## 가벼운 화면 5개 — 무엇을, 어느 API 로

전부 **이미 받는 응답**이다. 새 원천·새 계산·새 캐시 키 없음. 홈 카드와 같은 규칙 함수를 쓰는 곳은 그 함수를 그대로 부른다(두 화면이 다른 말을 하지 않게).

| 화면 | 내용 | 원천(기존) |
|---|---|---|
| `/s/calendar` 일정 | 오늘부터 30일: 내 종목 실적 발표·배당락·배당 지급 + FOMC + 미국 지표(CPI·PCE·고용). 날짜순 목록, 내 종목 배지. '오늘'·'이번 주' 구분선 | `/api/event-calendar` · `/api/macro-releases` · `FOMC_SCHEDULE`(홈 '주요 일정' 카드와 같은 셋) |
| `/s/gurus` 거장 | 거장 12명 카드(이름·운용사·한 줄 철학) → 누르면 상위 보유 10종목(비중·전분기 대비 증감) + "13F 는 분기마다 45일 늦게 공개돼요" | `guruFunds`(브라우저) · `/api/guru-portfolio` |
| `/s/brief` 오늘의 브리핑 | 홈 한눈 시황 3줄을 각각 펼친다 — ①시장(지수·환율·공포탐욕) ②내 종목(신호 종목 목록·7일 안 실적·크게 움직인 종목+기사 링크) ③다가오는 일정. 한 줄 문구는 홈과 **같은 `buildHomeBrief`** | `homeBrief.mineParts`·`buildHomeBrief` · `/api/timing-watch` · `/api/day-movers` · `/api/news-catalyst`(links) · `/api/market-indices` · `/api/exchange-rate` |
| `/s/news` 내 종목 뉴스 | 내 개별 주식마다 헤드라인 5개 + 기사 링크(새 창). ETF·코인은 "뉴스를 모으지 않아요" | `/api/news-catalyst`(`links`) |
| `/s/realestate` 부동산(배우기) | 학생용 4칸: 한은 기준금리 · 주담대 금리 · KB 아파트 매매지수 전년비 · 전국 미분양 + 서울 매매/전세 지수 선 하나(1년) + 한 줄 "금리는 집값의 중력이에요 — 금리가 오르면 집값은 눌리고, 내리면 뜨는 경향이 있었어요(예측 아님)" + 출처·기준월 | `/api/re-market`(kpi·kbChart — ECOS·FRED 실측 확정 항목) |

## 종목 상세 '더 알아보기' (접이식)

- 닫힌 상태 기본. 열면 5칸: PER(뜻 한 줄) · PEG · 시가총액 · 52주 위치(지금 가격이 52주 최고~최저 사이 어디 — 막대) · 업종 · 배당수익률(있으면). ETF·코인은 있는 칸만.
- 원천 `/api/stock-info`(`fundamentals.pe·peg·marketCap·high52w·low52w·sector·dividendYield`). 값이 'N/A'·null 이면 그 칸을 '없음'이 아니라 **'모름'** 으로.
- 분석 화면 링크는 두지 않는다(원칙 2).

## 검증 장치 — 문이 다시 생기지 않게

- `scripts/verify-simple-mode-exits.mjs`(야간 등록): `src/app/s`·`src/app/components/student` 의 모든 `href` 를 모아 `/s` 밖·외부 `https` 밖으로 가는 것을 센다. 허용 목록 = 상단 전환 버튼 2곳뿐. 그 밖에 하나라도 있으면 빨강. 마지막 줄 `✅ 전부 통과 (간편 화면 출구)`.
- 화면마다 폰·태블릿·PC 세 폭 실측(늘) · 없음/못 가져옴/로딩 3상태 · 넘침 0.
