## 기각·보류한 안

- **35개 화면 전체 리디자인** — 기각. 몇 주 걸리고 근본 원인("화면이 너무 많다")이 남는다.
- **증권사 캡처 자동 등록** — 보류. 이중 입력을 정면으로 풀지만 개인 계좌 데이터라 유료 키 전용(`personal: true`)·오인식 확인 단계가 필요하다. 접속 기록 4주치로 매매 빈도를 본 뒤 결정(사용자도 학생 매매 빈도를 모른다고 함 — "자주 안 하는 거 같은 느낌 정도").
- **`last_sign_in_at` 을 접속 지표로** — 기각. 세션이 유지되는 동안 갱신되지 않는다(실측).
- **홈에서 리그 API 로 총자산까지** — 기각. 리그는 금액 비공개 설계라 총자산이 없고 8초 걸린다.

## 미확인 가정

- 학생은 매매를 드물게 한다 → 홈은 '보기' 중심, 기록은 짧게. 4주 접속 기록으로 확인.
- 학생도 폰에서 주로 본다 → 폰 우선 설계, PC 는 같은 화면을 가운데 폭 제한.
