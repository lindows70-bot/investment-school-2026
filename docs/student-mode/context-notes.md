## 기각·보류한 안

- **35개 화면 전체 리디자인** — 기각. 몇 주 걸리고 근본 원인("화면이 너무 많다")이 남는다.
- **증권사 캡처 자동 등록** — 보류. 이중 입력을 정면으로 풀지만 개인 계좌 데이터라 유료 키 전용(`personal: true`)·오인식 확인 단계가 필요하다. 접속 기록 4주치로 매매 빈도를 본 뒤 결정(사용자도 학생 매매 빈도를 모른다고 함 — "자주 안 하는 거 같은 느낌 정도").
- **`last_sign_in_at` 을 접속 지표로** — 기각. 세션이 유지되는 동안 갱신되지 않는다(실측).
- **홈에서 리그 API 로 총자산까지** — 기각. 리그는 금액 비공개 설계라 총자산이 없고 8초 걸린다.

## 시장 탭 4단계 — 앱 환율 기준을 하나은행 매매기준율로 (2026-09-27)

- **원천**: `src/lib/fxHana.ts` — `api.stock.naver.com/marketindex/exchange` 한 번으로 9개 통화를 **같은 고시 회차**에서 받는다(하나은행 행만). 고시일은 `FX_USDKRW/prices` 첫 행을 쓰되 **값이 같을 때만** 붙인다(목록의 `localTradedAt` 은 고시 시각이 아니다 — 실측 목록 '09-26 05:45' vs 마지막 고시 09-23 회차 6255).
- **순서**: 하나은행 → fawazahmed0 → exchangerate-api → 마지막 성공값(30일) → 상수. fawaz 는 하나은행과 **동시에** 출발시켜 최악 대기가 늘지 않게 했다(소비측 8초 타임아웃).
- **통화가 하나라도 빠지면 통째로 다음 원천** — 통화마다 원천이 섞이면 교차 환율이 어긋난다.
- **엔화는 100엔당 고시**(864.09) → 값으로 판별해 1엔당으로 나눈다(`^TNX` 교훈 — 상수 나눗셈 대신 값 기반).
- **휴장일**: 마지막 고시가 그대로 오면 그게 은행이 지금 쓰는 값이라 '지금 환율'로 받는다. 10일 넘으면(최장 휴장 7일보다 넉넉히) 원천이 멈춘 것으로 보고 버린다.

## 규제 레이더 근거 기사 링크(2026-09-30, ae5846cb)
- **전**: 구글 뉴스 RSS 에서 제목만 모아 LLM 에 넘겼다 — 링크가 응답에 없어 화면이 요약뿐이었고, 항목이 어느 헤드라인에서 나왔는지 서버도 몰랐다.
- **후**: RSS 를 `<item>` 단위로 읽어 제목·링크 짝을 보존 → 프롬프트에 번호를 붙여 넘기고 항목마다 `srcIdx`(근거 번호 배열)를 **필수**로 받는다 → 서버가 1~N 범위만 인정, 하나도 못 대면 항목을 버린다 → 통과한 근거를 `sources`(제목·링크, 최대 3)로 실어 화면에 '근거 기사 1·2·3 ↗'(새 창). 연준 디코더의 srcIdx 가드와 같은 모양(CLAUDE.md "N개를 뽑아라 = 없으면 지어내라").
- **가드의 한계(연준 디코더와 같다)**: 번호가 유효한지만 본다. 그 헤드라인이 그 문장을 실제로 뒷받침하는지는 못 본다 — 그래서 링크를 화면에 병기해 학생이 직접 대조한다. climate·climateText 는 여전히 무검증.
- 링크는 구글 뉴스 리다이렉트 URL(news.google.com/rss/articles/…) — 원문으로 넘어간다. 원문 URL 을 직접 풀려면 리다이렉트를 따라가야 해 28건마다 요청이 늘어 하지 않았다.
