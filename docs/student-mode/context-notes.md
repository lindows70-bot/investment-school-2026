## 기각·보류한 안

- **35개 화면 전체 리디자인** — 기각. 몇 주 걸리고 근본 원인("화면이 너무 많다")이 남는다.
- **증권사 캡처 자동 등록** — 보류. 이중 입력을 정면으로 풀지만 개인 계좌 데이터라 유료 키 전용(`personal: true`)·오인식 확인 단계가 필요하다. 접속 기록 4주치로 매매 빈도를 본 뒤 결정(사용자도 학생 매매 빈도를 모른다고 함 — "자주 안 하는 거 같은 느낌 정도").
- **`last_sign_in_at` 을 접속 지표로** — 기각. 세션이 유지되는 동안 갱신되지 않는다(실측).
- **홈에서 리그 API 로 총자산까지** — 기각. 리그는 금액 비공개 설계라 총자산이 없고 8초 걸린다.

## 시안 반복 (Claude Design 캔버스 https://claude.ai/artifact/4THDHoK28RNSPeCjAcVvsa)

- 2판: 더리치·도미노·알파스퀘어 앱스토어 스크린샷 참고 → 머리글자 아이콘·추세선·자산 대 원금 차트·친구 포트폴리오 카드. 알파스퀘어의 매매 타이밍 화살표는 WHAT/WHEN 분리 원칙으로 기각.
- 3판: 제미나이 의견. 채택 = 코어/위성 배지·총액 요약 카드·수익률 계산 ? 도움말·간편/분석 모드 스위치·태블릿 세로 화면.
  **기각 = 시세 실패 시 가격 수동 입력**(출처 없는 숫자 — 홈은 '못 가져왔어요'로 밝힌다. 매매 체결가 수정은 원래 가능) ·
  **Tailwind 코드 프롬프트**(인라인 스타일 + TK 토큰 앱이라 제1원칙-b 위반).
- 4판: 챗지피티 의견. 채택 = 원금·불어난 돈을 총자산과 한 덩어리로 · 리그 한 줄 · 코어/위성 우리말 병기(기본/전략 투자) ·
  오늘의 투자 체크(사실만, 신규 자금 제안 — HOLD 원칙상 매도 권유 금지) · 종목 상세 화면 · 기록 빠른 선택 칩 · 매수가(입력) vs 지금 시세(참고) 분리 ·
  친구 '왜 달랐을까' 특징(섹터·국가는 기존 SSOT — 국가는 `etfLookThrough.countryWeights`, 상장 시장으로 세지 않는다) · 전체 메뉴 → 5분류 · 추세선 회색.
  **기각 = "잠시 지연되고 있습니다" 문구**(원인을 모르면서 '잠시'라고 단정 — '지금 시세를 못 가져왔어요'로 사실만) ·
  **분산점수 78점 같은 습관 점수**(정의·산정 근거 없는 점수 = 가짜 정밀. 순위 변화도 순위 이력 저장소가 없어 보류).
  **보류(사용자 결정) = 오늘의 미션**(누가 미션을 쓰나 — 선생님 직접 vs 보유 종목에서 자동) · 코어/위성 우리말 표기가 수업 용어와 맞는지.
