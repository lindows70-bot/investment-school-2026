# 학생 간단 모드 4단계 구현 계획 — 학생 공개(로그인 착지) · 폰 앱 설치 · 나가는 길

> subagent-driven-development. 작업마다 검토 → 수정 → 재검토.

**Goal:** 학생이 로그인하면 **학생 홈(`/s`)** 으로, 선생님은 지금처럼 **대시보드**로 간다. 학생도 원하면 '분석 화면'(기존 화면)으로 바꿔 쓸 수 있고, 그 선택이 다음 로그인에도 유지된다. 폰 홈 화면에 앱으로 설치할 수 있게 한다.

## Phase 0 실측 (2026-09-26)

| 항목 | 지금 |
|---|---|
| 로그인 뒤 이동 | `login/page.tsx` `redirectToDashboard()` → `/dashboard`(하드 이동) · 미들웨어: 로그인 상태로 `/login` 오면 `/dashboard` · `src/app/page.tsx` 도 `/dashboard` |
| 로그인 안 한 채 보호 경로 | `/login` 으로(원래 가려던 주소를 기억하지 않음) |
| 역할 | `profiles.role` — teacher 1 · student 8 |
| 접속 기록 | ⚠️ `student_visits` 테이블 **없음**(SQL 미실행) — 사용자 실행 필요 |
| 앱 설치 | 매니페스트·PNG 아이콘 없음(`public/logo-icon.svg` 만) · `viewport.themeColor '#080B11'` · `viewportFit: 'cover'` 있음 |
| 폰에서 나가는 길 | 홈 인사 줄 '분석 화면' 링크만 · 로그아웃은 PC 왼쪽 메뉴에도 없음 |

## 정한 것

- **착지 규칙 한 곳**: 새 경로 `/start`(서버)가 역할과 화면 모드 쿠키를 보고 보낸다.
  - 쿠키 `view_mode = simple | full`(1년). 없으면 학생 → `/s`, 선생님 → `/dashboard`.
  - 로그인 화면·미들웨어(로그인 상태로 `/login`)·루트 `/` 가 모두 `/start` 로 간다.
- **원래 가려던 곳으로**: 로그인 안 한 채 보호 경로에 오면 `/login?next=<경로>`. 로그인 뒤 `next` 가 **같은 사이트 내부 경로**(`/` 로 시작, `//` 아님)면 그리로, 아니면 `/start`.
- **모드 바꾸기**: 학생 홈 '분석 화면' 링크 → `view_mode=full` 저장 후 `/dashboard`. 기존 화면 사이드바에 **'간편 화면'** 링크 → `view_mode=simple` 저장 후 `/s`(선생님도 볼 수 있음).
- **학생 셸 로그아웃**: PC 왼쪽 메뉴 아래 + 배우기 화면 맨 아래 '내 계정' 줄(분석 화면으로 바꾸기 · 로그아웃).
- **폰 앱 설치(PWA)**: `app/manifest.ts`(이름 '2026 투자학교', `start_url: '/start'`, `display: standalone`, 색 = 토큰) · 아이콘 192·512 PNG + apple-touch-icon(로고 SVG 를 PyMuPDF 로 변환) · 최소 서비스 워커(네트워크 그대로 — 캐시로 옛 화면을 보이지 않게) · 배우기 화면 '폰 홈 화면에 앱으로 추가하기' 카드(안드로이드 = 설치 버튼, 아이폰 = 공유 → 홈 화면에 추가 안내, 이미 설치됐으면 숨김).

## 경계
- **절대**: 선생님 착지를 바꾸지 않는다(쿠키로 본인이 바꿀 때만) · 외부 주소로 `next` 이동 금지(열린 리다이렉트) · 서비스 워커가 API·화면을 캐시하지 않는다.
- **물어보고**: 접속 기록 SQL 실행(사용자) · 4주 뒤 측정 방식.
