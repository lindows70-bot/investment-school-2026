
## 4. 파생 지표 계산 함수 검증

### 4-1. 역사 백분위 — 3개 구현, 공식 동일 ✅

| 지표 | 파일:줄 | 공식 |
|---|---|---|
| 미분양 백분위 | `re-market/route.ts:93-95` | `round( count(x ≤ now) / n × 100 )` |
| 괴리 백분위 | `re-gauge/route.ts:98-99` | `round( count(g ≤ gapNow) / n × 100 )` |
| 스프레드 백분위 | `re-rent/route.ts:78-79` | `round( count(s ≤ now) / n × 100 )` (n ≥ 24 요구) |
| 공급 백분위 | `re-supply/route.ts:57-59` | 동일 (n ≥ 24 요구) |

- **전부 "현재값 이하" 포함(≤) 방식**으로 일관. 최댓값이면 100%가 나온다.
- 판정 임계는 지표별로 다름: 괴리 `≥85 hot / ≥65 warm / ≤20 cool`(`re-gauge:100`), 스프레드 `≥70 / ≤30`(`RentYieldSpread.tsx:29-31`).
- ✅ **수식이 화면 설명("역사 백분위로 판정")과 일치.**

### 4-2. 근본가치 괴리 **−28.2%** — ⚠️ 화면 문구와 부분 불일치

- **계산** (`src/app/api/re-gauge/route.ts:80-99`):
  ```
  base = months[0]                                      (89행)
  fund(t) = ( 전세지수(t) / 주담대금리(t) ) / f0 × 100   (93행)   ← f0 = 기준월의 전세/금리
  sale(t) = 매매지수(t) / s0 × 100                       (92행)
  gap(t)  = ( sale / fund − 1 ) × 100                    (94행)
  ```
  - 주금공(HF) 프레임: **근본가치 ∝ 임대료(전세) ÷ 할인율(주담대금리)**
  - 입력: KB 서울아파트 매매 `901Y062/P63ACA` ∩ 전세 `901Y063/P64ACA` ∩ 주담대 `121Y006/BECBLA0302`
  - `months`는 세 계열의 **교집합**(87행), `base`는 그 첫 달 = 주담대 시계열 시작 **2004-01**에 종속
- **−28.2%의 의미**: 매매지수가 (기준월 대비) 근본가치 대비 **28.2% 아래**. 즉 "저평가 쪽".
- ⚠️ **화면 문구 불일치 2건**:
  1. `ReDeepGauges.tsx:50` — "가격이 근본가치에서 **얼마나 떠 있는지**". 값이 음수면 '떠 있는' 게 아니라 '밑돌고' 있다. KPI 라벨(`58행` "현재 괴리(가격/근본가치)")은 중립적이라 문제없으나, 설명문은 상승 방향만 전제한다.
  2. `ReDeepGauges.tsx:15` `cool` 판정 설명 — "가격이 사용가치에 **근접**". −28.2%는 근접이 아니라 **하회**다.
  - → 수식 자체는 정상. **설명 카피만 양방향으로 고치면 된다.**
- ⚠️ **더 중요한 한계**: `gapNow`의 절대값은 **기준월(2004-01) 선택에 100% 종속**된다. 코드 주석(`81행`)도 "기준시점 민감(보고서 자체 비판) → 절대 gap이 아니라 역사 백분위로 판정"이라고 **명시**하고 있다. 즉 **앱은 −28.2%를 판정 근거로 쓰지 않는다** — `gapPercentile`로 판정한다(`100행`).
  - → **영상에서 "−28.2% 저평가"를 단독 근거로 인용했다면, 앱의 설계 의도와 다르다.** 같이 나오는 `역사 백분위 N%`를 함께 말해야 앱과 일관된다.
- **병목 표시**: `re-gauge:101-112` — 세 입력의 각자 최신월을 비교해 무엇이 결과를 멈춰 세웠는지(`bottleneck()`, `lib/dataFreshness.ts:121`) 화면에 명시. 통상 지연은 `TYPICAL_LAG`(`dataFreshness.ts:100-116`)에 실측 등록: KB 1개월, 주담대 2개월, 전환율 2개월, 소비심리 2개월, 미분양 2개월.
