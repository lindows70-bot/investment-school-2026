# 현금 등록 — 컨텍스트 노트

## 채택하지 않은 안과 이유
- **증권사 예수금 자동 연동** — 토스 등 실거래 API는 IP 허용목록·개인 계좌 경계(TOSS_OWNER_EMAIL fail-closed)라 학생 전원에게 불가. 직접 입력이 유일한 정직한 경로.
- **현금을 investments 행으로 저장** — 35개 화면이 investments를 읽는데 현금 행이 섞이면 수익률·평가액·분류가 전부 오염(퀀트빌더 가상종목 사건과 동일 클래스). 별도 테이블이 정답.
- **막스 밴드를 주간 리포트에도 그대로** — 주간 리포트는 온도 fetch가 없어 사이클 무관 범용 임계(5/10%) 사용, 사이클 연동 판정은 막스 시계추로 안내(축 차이 명시).

## 임계값 근거
- 밴드(30~40/20~30/15~25/10~20/10~15)는 기존 MarksCycle·브리핑 인라인 값을 `cashBandOf` SSOT로 승격 — 새 숫자 발명 0(3곳이 같은 산식을 각자 갖고 있던 것을 통합).
- 판정 경계 포함 규칙: min·max **경계값은 밴드 안**(20.0%·30.0% = inband) — "권장 밴드를 지켰다"가 자연스러운 해석.
