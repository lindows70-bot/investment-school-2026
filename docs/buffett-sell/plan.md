# 🏰 버핏 매도 점검 — 설계 (2026-08-08)

## 목적
"언제 파는가"에 버핏의 기준을 결정론으로 — 가격이 아니라 **기업이 변했는가**를 묻는다.
고평가 단독 매도 강요 금지(HOLD_DIP) 원칙과 충돌하지 않는 유일한 매도 축.

## 버핏 원칙 → 판정 매핑 (Phase 0 실측 완료)
| 원칙 | 판정 | 데이터 |
|---|---|---|
| ① 해자 침식 | 연간 총마진이 4년 고점 대비 −5%p↓ **그리고** (최신=기간 최저 또는 2년 연속 하락) | fundamentalsTimeSeries(annual·financials) — US·KR 실측 OK |
| ② 이익의 실재 훼손 | 영업흑자인데 OCF 적자(quality_gap) | stock-fcf SSOT 재사용 |
| ③ 논거 붕괴 | 매수 시점 스냅샷 대비 성장 소멸·분류 변질 | 기존 '매수 이유 유효성 점검' 재사용 |
- 대조군 검증: INTC 발동(42.6→32.7%p·OM −8.9%) / NVDA 미발동(고점 −3.9%p) / 삼성전자 미발동(2023 침체 후 회복 — '최신=최저' 조건이 일시 침체를 걸러줌)

## ❌ 기각한 것
- **내부자 매도** — 데이터는 있으나(NVDA 11건 $574M) 보상성·분산 매도 노이즈가 커서 건재 기업도 발동. 버핏 원칙도 아님.
- **경영진 신뢰** — 정량화 불가. 지어내지 않는다.
- **incomeStatementHistory** — 2024-11부터 죽은 모듈(총이익 전부 0 실측). fundamentalsTimeSeries로.

## 신호 강도
2개+ 해당 = 🔴 강력 매도 검토 / 1개 = 🟡 주의 관찰 / 0개 = 통과.
문구는 "기업이 변했다"는 사실 서술 + 근거 병기 — 지시가 아니라 판단 재료.
