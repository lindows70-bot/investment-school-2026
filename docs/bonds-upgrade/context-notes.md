## 실측이 설계를 바꾼 것 ①: "역전 = 음수"로 경보를 울리면 남발된다

5거래일 이상 연속 음수만 세도 **T10Y2Y 역전 에피소드가 21건**이다. 그런데 내용이 전혀 다르다.

| 성격 | 사례 | 결과 |
|---|---|---|
| **얕고 짧음(노이즈)** | 1988-12(7일·−0.03%p) · 1998-07(5일·−0.03%p) · **2025년에만 6건**(5~18일·−0.04~−0.27%p) | 대부분 아무 일 없었음 |
| **깊고 김(진짜)** | 1978(423일·−2.41) · 1980(278일·−1.70) · 2000(220일·−0.52) · 2006(147일·−0.19) · **2022(534일·−1.89)** | 7~23개월 뒤 침체 — **2022는 예외** |

→ **경보를 3단계로 나눈다.** 🟡평탄(0~0.25%p) / 🟠짧은 역전(<10거래일) / 🔴지속 역전(≥10거래일).
**Red Alert는 🔴에서만** 대시보드·브리핑으로 나간다. 짧은 역전은 채권 페이지 안에서만 알린다.

⛔ **그리고 화면은 반드시 2022년 사례를 함께 말한다** — 534일·−1.89%p로 역사상 손꼽히게 깊고 길었는데
**침체가 오지 않았다**(2024-12 해소, NBER 침체 없음). "역전=침체"를 단정하면 그 순간 거짓말이 된다.
리드타임도 7~23개월로 편차가 커서 **타이밍 도구가 아니다**.

## 실측이 설계를 바꾼 것 ②: 인하 사이클을 "침체 여부"로 가르면 틀린다

사용자 질문 *"경기가 좋을 때 금리인하하면?"* 을 자동 분류하려 했더니 **오분류 3건**이 바로 나왔다.

| 사례 | 침체 시작 기준 판정 | 실제 |
|---|---|---|
| **1975-11** (실업률 8.3%·12M **+1.7%p**) | 🟢 보험성 | ❌ 1973~75 침체 **직후 회복기**. 실업률 급등 중인데 "경기 양호"는 거짓 |
| **1992-08** (실업률 7.6%·+0.7%p) | 🟢 보험성 | ❌ 90~91 침체 후 jobless recovery |
| **2019-10** (실업률 3.6%·−0.2%p) | 🔴 위기성 | ❌ 실제로는 **보험성 인하**. ±12개월 규칙이 **코로나(외생 충격)** 를 잡아 오분류 |

→ **판정 축을 바꿨다.** 침체 시작 여부가 아니라 **인하 시점의 경기 상태**(실업률 수준 + 12개월 추세)로 가른다.
그게 사용자가 물은 "경기가 좋을 때"의 정확한 정의다. 침체 동반 여부는 **결과**로 따로 보여준다(원인과 결과를 섞지 않는다).

## 실측이 설계를 바꾼 것 ③: `range=max` 가 또 다운샘플했다

`^GSPC?range=max&interval=1mo` → **168건**(1984-12~2026-08 = 501개월이어야 함). 3배 다운샘플.
같은 요청에 `^DJI`는 416건으로 정상 — **심볼마다 다르다.**
`period1` 을 명시하면 ^GSPC **501건 정상**. → 코인랩과 같은 함정, 같은 처방: **요청 간격이 아니라 반환 개수로 검증**.

## 채택하지 않은 안과 이유

| 안 | 기각 사유 |
|---|---|
| `DGS10 − DGS2` 를 직접 계산 | FRED가 `T10Y2Y` 공식 계열을 준다. 직접 빼면 결측일 처리가 달라져 공식값과 어긋난다(제2원칙). |
| NBER `USREC` 로 실시간 침체 경보 | **후행 발표**다(2008-12에 2007-12 시작을 선언). 실시간엔 무용 — 과거 대조에만 쓴다. |
| 3년 전체 상관 하나만 표시 | 평온기와 발작기를 평균내면 밋밋해진다(TLT↔SPY 3년 0.16). 사용자가 물은 건 **"채권이 발작할 때"** 다 → **조건부 상관**으로 간다. |
| `^MOVE` 레벨과 TLT 수익률의 상관 | 레벨 vs 수익률이라 −0.16이 나와도 의미가 약하다. MOVE는 **변화율**로 비교하거나 국면 판정용 레벨로만 쓴다. |
| 역전 임계를 −0.5%p 같은 깊이로만 | 2006-08 역전은 최심 −0.19%p였는데 147일 지속 후 침체가 왔다. **깊이보다 지속이 낫다** — 지속을 1순위, 깊이를 보조로. |
| 인하 사이클별 주가 성과를 1954년부터 | ^GSPC 야후 이력이 **1985-01부터**다. 1986년 이후 인하 사이클만 자산 성과를 붙이고 그 이전은 금리·실업률 경로만 — **표본 한계를 화면에 명시**. |

## 임계값 근거

- 🔴 지속 역전 = **연속 10거래일** — 침체를 선행한 역전은 전부 100일 이상이었지만, 확정까지 기다리면 경보로서 무용하다. 10일은 "하루짜리 노이즈"를 거르는 최소선이고, 실제 지속일수를 화면에 숫자로 함께 띄워 판단을 학생에게 넘긴다.
- 🟡 평탄 = **0.25%p 미만** — 기존 bonds 라우트가 0.3%p를 쓰고 있어 근접값. 곡선이 평탄해지는 국면 경고.
- 채권 발작일 = **10Y 금리 일간 변동 ≥ ±10bp** 또는 TLT 일간 |수익률| 상위 10%.
- 인하 유형 = 실업률 12개월 변화 **< +0.5%p** 이고 침체 중이 아니면 보험성(Sahm 룰 0.5%p 임계와 같은 잣대).
