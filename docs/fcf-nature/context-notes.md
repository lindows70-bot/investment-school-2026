## 채택하지 않은 안과 이유
- **지주회사 별도 판정**: 판별 필드가 없다(위). 이름 규칙("지주·홀딩스")은 HD현대·LG를 못 잡음 → 기각.
  대신 "다년 평균 병기"가 지주든 사이클이든 원인 무관하게 대표성 문제를 잡는다.
- **CV(변동계수) 임계**: S-Oil처럼 avg≈0이면 CV가 21.77로 폭발(분모 문제) → 괴리 비율(avg/ttm)로 대체.
- **3년 평균으로 yield 자체를 교체**: 숫자를 지우면 안 된다(기존 원칙) — TTM 표시 유지 + 평균 병기 + 점수만 보수.
- **사이클 저점 안내**(ttm<avg인 CVX·EQNR에 "올해가 저점일 수도") — 매수 유도 문구가 될 위험 → 이번엔 제외.
