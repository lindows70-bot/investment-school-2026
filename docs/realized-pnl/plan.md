# 💰 실현손익 통합 — 설계 (2026-08-05)

## 목적
학생이 대시보드에서 "나 −₩541만 잃었다"고 읽는다. 그런데 실제로는 매도 11건으로
**+$3,879.93(≈₩555만)을 이미 벌어 확정**해 뒀다. 화면이 절반만 보여줘서, 학생이
자기 성적을 정반대로 이해하고 잘못된 결정(공포 매도·전략 포기)을 한다.
해결되면 학생이 **평가 + 실현 = 진짜 성적**을 보고, "이번 달 실제로 얼마 벌었나"에
답할 수 있다(7월엔 XBI·IBB 매도로 +$2,309를 실현했는데 월별 차트는 −442만만 보여준다).

## 데이터 (Phase 0 실측 — 2026-08-05)
- ✅ `transactions` 테이블: `type='sell'` · `realized_pnl`(통화 단위) · `transaction_date` ·
  `currency` · `market` · `ticker` · `name`. 매도 11건 전부 US/USD.
- ✅ 합계 검산: 화면 표 11건 수기 합 = **+$3,879.93** = `/api/tax-helper` 의 `realizedUsUsd` **정확히 일치**
- ✅ 환율 이력: `getTechCandles('KRW=X','US','D')` 재사용(monthlyPnl 과 동일 SSOT)
- ⚠️ CRYPTO 매도는 0건(현재) — 있어도 과세는 유예지만 **성적 집계에는 포함**한다(세금과 성적은 다른 축)
- 재사용: `monthlyPnl.ts` 의 월 순회·환율 조회 로직

## 계산 (결정론)
- 월별 실현손익 realized(M) = Σ(그 달 매도 거래의 `realized_pnl` × 환율)
- 환율은 **매도일 종가 환율**(그날 원화로 확정된 금액이므로). KRW 거래는 1.
- 월별 총손익 = 평가손익 변화분(기존 pnl) + realized(M)
- 대시보드 총 손익 = 평가손익(현재) + 실현손익 누계

## 정직 캐비엇 (UI에 명시)
- 실현손익은 **매도일 환율**로 환산(평가손익은 현재 환율) — 두 축의 환율 기준이 다르다
- 배당·수수료·세금 미포함
- 실현손익은 이미 확정된 금액이라 시세가 변해도 바뀌지 않는다

## 구현
- `src/lib/realizedPnl.ts` — 월별 집계 SSOT(순수 함수 + 수집)
- `/api/monthly-pnl` — 서버에서 인증 후 transactions 를 읽어 `realizedByMonth` 동봉
- 대시보드: ① 총 손익 카드(평가+실현) ② 월별 차트에 실현손익 시리즈
- 캐시: 개인 데이터라 무캐시(환율 캔들만 공유 캐시)
