# 📉 커버드콜 X-Ray — 설계 (2026-08-01)

## 목적
"분배율 15~20%"에 끌려 커버드콜을 담기 전에, **본주 대비 총수익(TR)이 얼마나 뒤처지고 원금(가격)이 얼마나 깎였는지**를 숫자로 보게 한다. 배당 인컴 랩의 기존 경고("분배율이 높다고 총수익은 아닙니다")는 정성 문구뿐이라 실제 크기를 알 수 없었다.

## 데이터 (Phase 0 실측 2026-08-01)
- ✅ Yahoo `chart` **adjclose = 배당 재투자 반영 총수익**, `close` = 가격만 → 둘을 나누면 분배 기여분이 분리된다. KR ETF도 `.KS`로 동일 제공(494300·482730·458760·486290 실측)
- ✅ 종목명 전수 확인으로 벤치마크 매핑 검증(482730=TIGER US S&P500 +10% Premium → SPY 등)
- ❌ YMAG·YMAX·ULTY는 **펀드of펀드**라 단일 본주가 없음 → X-Ray 대상 제외(정직)

## 계산 (결정론)
- 커버드콜·본주의 **공통 거래일 교집합**에서 시작·종료를 잡는다(상장일이 다르면 비교가 불공정 — 상관 레이더 패턴)
- `trGap = TR(커버드콜) − TR(본주)` · `navChange = 가격 변화` · `distContrib = TR − 가격`
- 판정: gap ≥ −2%p 추종 양호 / −2~−10 뒤처짐 / < −10 크게 뒤처짐 + **가격 하락이면 '원금 침식' 별도 경고**(분배가 원금에서 나온 정황)
- 기간 1년·2년·전체(공통 최대) 3종 동시 산출 — 한 기간만 보면 결론이 뒤집힌다
