### 3단계 분리(60봉) — 가장 중요한 발견

⭐ **결정타 = 레짐 행.** 고점권(92~98%)의 +2.46 edge는 같은 상승추세(200일선 위) 종목들과
비교하면 **소멸**한다(−1.11). 즉 edge의 정체는 "신고가 근처라서"가 아니라 **"건강한 상승추세라서"**다.
그리고 갓 신고가를 찍은 지점(≥98%)은 같은 추세 종목들보다도 **명확히 나쁘다**(−3.67).

### 결론 3줄
1. **"달리는 말에 올라타라"는 반만 맞다** — 말(상승추세)은 맞고, 올라타는 순간(신고가 돌파 직후)은 틀렸다.
2. 신고가 자체는 독립 매수 신호가 아니다. 유효한 건 이미 검증된 **추세 구조 + 눌림(정예 타점 절사 +1.8)**.
3. 따라서 신규 판정기를 만들지 않는다 — 신고가는 **모집 필터·교육 라벨**, 판정은 기존 SSOT(6축·타점)로.

## 채택하지 않은 안과 이유
- **"신고가 = 매수 신호"로 점수/추천에 반영** → 기각. ≥98% US 절사 −3.55·승률 −12.5pp(20봉).
  WHAT/WHEN 분리 원칙과도 충돌. (RS '강한 걸 사라' 기각과 같은 계열 — '이미 오른 것'≠'앞으로 오를 것')
- **hi52 전용 신규 점수 축** → 불필요. 레짐 분리로 edge가 추세 효과로 환원됨 — 기존 신호등·정예 타점이 이미 그 축.
- **KR 중위 +10.19를 근거로 KR만 완화** → 기각. n=37 + 평균 +0.20(꼬리 재앙) = 2026 상반기 KR 불장
  국면 의존(3단계 시점 분산 위반). 국면이 바뀌면 반대로 돈다.

## 임계값 근거
- 92% / 98% 경계: 기존 앱 관례 재사용(ChaseBadge 고점권 76~92 / 신고가권 >92, 로테이션 스캐너 HI_NEAR 98).
- 전방 20·60봉 병행: 해부 스킬 0절("구간 하나만 보면 정반대 결론").

## 검증에서 발견한 것
- 기존 자산: 로테이션 시계의 "52주 신고가 × 소섹터 국면 스캐너"(hi52≥98 · 주도/태동/과열 라벨)가 이미 있음
  — 단 맥락 라벨뿐, 펀더멘탈·타점·매수 판정 없음. tech-screener가 종목별 52주 위치를 이미 매일 계산(647종).
- 200선 아래에서 신고가권 표본 = 0~2건 — 신고가권은 정의상 거의 전부 상승추세(레짐 분리가 꼭 필요했던 이유).
