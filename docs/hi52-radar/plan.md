# 🐎 신고가 레이더 — 설계 (2026-07-30, 사용자 승인 대기)

## 목적
"달리는 말에 올라타라" — 52주 신고가권 종목만 따로 모아 **지금 사도 되는지**를 판정.
백테스트가 준 답: 말(추세)은 타되 **말이 숨 고를 때**(신고가 부근 눌림) 타야 한다.
갓 돌파(≥98%) 추격은 우리 표본에서 명확히 나쁘다(US 절사 −3.55 · 20봉 승률 −12.5pp).

## 데이터 (Phase 0 실측 — context-notes 판정표)
- ✅ 재사용만으로 가능(신규 수집 0): tech-screener 유니버스 647종 일별 캔들 캐시(hi52 기계산) ·
  macro-screened-universe(6축 소점수) · entryTiming SSOT(신호등·정예 타점·과대이격) ·
  sector-rotation 캐시(소섹터 국면) · isPegBaseEffect 가드
- ❌ 안 하는 것: hi52 기반 신규 점수·판정기(백테스트 기각 — 판정은 기존 SSOT로)

## 계산 (결정론)
모집 = hi52 ≥ 92%(52주 최고 종가 대비). 두 그룹으로 분리:
- 🎯 **올라탈 자리**: 92~98% + 신호등 green + (정예 타점 or 첫눌림목) + 가드 통과
  (급락·과대이격·하락다이버전스·기저효과 PEG 아님) + 통합 6축 하한(65)
- ⏳ **달리는 중 — 추격 대기**: ≥98% 또는 과대이격 — 관찰만(교육: 근거 수치 병기)
정렬 = 통합점수(WHAT). ⛔ hi52는 점수에 절대 미반영(모집 필터·라벨만).

## 정직 캐비엇 (UI 명시)

모멘텀 크래시 경보 연동 · 예측 아닌 현재 위치 · 신고가 자체는 매수 신호가 아님(측정 근거 병기)

## 구현 (승인 시)

- API: `/api/hi52-radar`(공개·일별 캐시·크론 워밍은 tech-screener 09:10 뒤에 무료 편승)
- 화면: `/hi52-radar` — 그룹 2개 + 스파크라인 + 기술적 차트/종합판정 딥링크 + 백테스트 수치 카드
