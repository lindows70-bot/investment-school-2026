- 칩 규칙: 채권·금·코인 = 미국 계절 · 부동산 = 한국 계절 · 주식 = 미국, 한국 칩이 다르면 "미국 X · 한국 Y". 화면 공식 카드와 각 칸 상세에 "수업 원칙이에요 — 과거 경향이지 약속이 아니에요". 칩 색은 중립(등락색 아님).

## 4단계 — 배우기 요약 · 오늘 바뀐 칸 · 내가 가진 줄 · 저울의 용어 (2026-09-29)
- **요약 카드**(`components/student/learn/ScaleSummary.tsx`): 배우기 '더 알아보기' 맨 위 — 5줄 × ①②③ 칩만(문장·숫자는 저울 화면에서) + 바뀐 칸 한 줄. 칸 전체가 `/s/scale` 링크.
