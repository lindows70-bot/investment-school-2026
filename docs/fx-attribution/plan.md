# 💱 환율 기여도 분해 — 설계 (2026-08-01)

## 목적
"달러로는 벌었는데 계좌는 왜 마이너스지?"를 숫자로 답한다. 지금 앱은 해외 종목 수익을 **원화 한 덩어리**로 보여줘서, 그 안에 섞인 환율 손익이 안 보인다. 오늘 자산관리 KPI·커버드콜 X-Ray가 연달아 환율 때문에 틀렸는데, 정작 학생에게 환율 축을 보여주는 화면이 0개였다.

## 데이터 (Phase 0 실측 2026-08-01)
- ✅ `investments.purchase_date` — USD 보유 **26행 전부 존재(100%)**, 2025-03 ~ 2026-07 분포
- ✅ Yahoo `KRW=X` 일봉(409일 수신) → 매입일 환율 조회 가능(휴장일은 직전 거래일)
- ✅ 실측이 의미 있는 수치를 냄: 교사 포트 전체 **환율 기여 −2.1%p**, 7월 매수분은 −5~6%p
- ⭐ **부호가 뒤집히는 종목 실재**: PHO 달러 +1.8% → 원화 −4.4% / XLP +0.3% → −5.2%

## 계산 (결정론)
- 행 단위(분할매수는 매입일이 달라 행마다 환율이 다름):
  - 달러 수익률 = 현재가/매입가 − 1
  - 원화 수익률 = (현재가×현재환율)/(매입가×매입환율) − 1
  - **환율 기여 = 원화 − 달러**
- 포트 합계는 원가(원화 환산) 가중
- 환노출 비중 = USD 자산 평가액 / 전체 평가액
- 시나리오: 환율이 ±5%·±10% 움직일 때 원화 평가액 변화(선형 — 환율만 변하는 가정)

## 정직 캐비엇
- 매입일 환율 = **그날 종가**(실제 체결 환율·증권사 환전 스프레드와 다름) · 배당·수수료 미반영 · 원화 상장 해외 ETF(TIGER 미국S&P500 등)는 **이미 원화 표시라 이 분해 대상이 아님**(내부적으로는 환노출이 있으나 앱이 원화로만 보유) · 예측 아닌 과거 분해
